# Karla for the Gruvbox palette

These unmodified WOFF2 subsets are from the Google Fonts Karla v33
stylesheet (`https://fonts.googleapis.com/css2?family=Karla:ital,wght@0,400..700;1,400..700&display=swap`, using a modern Chromium user agent).
`build.mjs` embeds the four subsets and the upstream [SIL Open Font License](OFL.txt) into the single-file plugin. No fonts are fetched at runtime. Other scripts fall back to the platform sans face.
